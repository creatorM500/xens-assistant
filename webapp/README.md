# AINSLUP Web

Web app separada del Desktop, preparada para desplegarse en Vercel.

## Desarrollo

```bash
cd webapp
npm install
npm run dev
```

En Vercel, configura **Root Directory** como `webapp`. Las siguientes fases conectarán Supabase Auth, créditos, chat y pagos. No pongas claves privadas en variables públicas del navegador.
