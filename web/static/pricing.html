Cómo leer los créditos: 1 Ainslup Credit = 1.000 tokens base-equivalentes. El consumo depende del texto enviado, la respuesta y el modelo; no existe un precio fijo por conversación. Los créditos se renuevan el primer día de cada mes y no se acumulan.

AINSLUP usa alias funcionales (Flash, Core, Think, Code, Vision y Ultra). El proveedor y modelo concreto pueden cambiar por precio, disponibilidad, rendimiento o seguridad. Consulta la aplicación para ver el modelo activo; no se garantiza un modelo concreto. Ver Términos §3.1.

¿Puedo cancelar cuando quiera?

Sí. Puedes cancelar tu plan Pro o Premium en cualquier momento desde la configuración de tu cuenta, sin penalidades.

¿Qué pasa si agoto mis Ainslup Credits?

Las nuevas solicitudes que consumen créditos se detienen hasta el primer día del mes siguiente. Las tareas ya iniciadas pueden terminar. Puedes cambiar a un plan superior si necesitas continuar antes.

¿Cuántas conversaciones incluye cada plan?

No hay un número fijo: una conversación corta consume mucho menos que una conversación larga con historial, herramientas o razonamiento. Como referencia, una interacción estándar Core cuesta unos 3 créditos: aproximadamente 1.600 interacciones con Free, 5.000 con Lite, 11.600 con Pro y 41.600 con Premium. Son estimaciones, no un límite de conversaciones.

¿Cuánto cuesta un modelo avanzado?

El coste se calcula con el multiplicador del modelo activo y los tokens reales. Los ejemplos de modelos son orientativos y pueden cambiar; la aplicación debe mostrar el modelo y coste aplicables. Las respuestas largas o con mucho contexto consumen más.

¿Cuánto consume una imagen?

Actualmente, generar una imagen no descuenta Ainslup Credits. Se procesa mediante Pollinations y puede estar sujeto a sus límites y disponibilidad. Si esta política cambia, se mostrará el coste antes de generar la imagen.

¿Se acumulan los créditos no utilizados?

No. Los créditos son mensuales, no se transfieren al mes siguiente y se renuevan automáticamente el primer día de cada mes.

¿Cómo decide AINSLUP qué modelo usa?

AINSLUP optimiza el costo por tarea: las tareas sencillas se resuelven con modelos económicos y solo las complejas usan los modelos más capaces de tu plan. Si un proveedor falla, hay un sistema de respaldo para que la conversación nunca se interrumpa.

¿Qué es un Ainslup Credit?

Un Ainslup Credit equivale a 1.000 tokens base-equivalentes. Cada tarea consume créditos según el modelo utilizado: los modelos económicos cuestan menos créditos que los de frontera.

¿Qué métodos de pago aceptan?

Tarjetas de crédito y débito. Los pagos se procesan de forma segura a través de nuestro proveedor de pagos.
