Términos de Servicio

Última actualización: 2026-08-15

Bienvenido a XENS, un producto operado por SvY Teck ("nosotros", "la empresa"). Al crear una cuenta o usar la plataforma, aceptas los siguientes términos. Si no estás de acuerdo, no debes utilizar el servicio.

1. Descripción del servicio

XENS es un asistente conversacional de inteligencia artificial accesible vía web, ofrecido bajo un modelo de suscripción con un plan gratuito limitado y planes de pago con funciones adicionales.

2. Cuentas de usuario

Para usar XENS debes crear una cuenta con información veraz. Eres responsable de mantener la confidencialidad de tus credenciales y de toda actividad que ocurra bajo tu cuenta.

3. Planes y facturación

  • El Plan Gratuito ($0) incluye 5.000 Xens Credits por mes, memoria básica, calendario, metas y base de conocimiento, navegación web de solo lectura y analítica básica de uso. La cantidad de créditos puede cambiar sin previo aviso.
  • El Plan Lite ($5/mes) incluye 15.000 Xens Credits por mes, acceso a XENS Flash/Core/Vision, memoria completa y navegación web completa.
  • El Plan Pro ($10/mes) incluye 35.000 Xens Credits por mes, acceso a XENS Flash/Core/Think/Code/Vision, memoria completa, navegación web completa, archivos, ejecución de código, control del equipo, correo y hasta 2 sub-agentes.
  • El Plan Premium ($30/mes) incluye 125.000 Xens Credits por mes, acceso a todos los modelos XENS incluido Ultra, y todas las funciones Pro más multiagente hasta 4, video completo y plugins.
  • Los Xens Credits se renuevan el primer día de cada mes. Un Xens Credit equivale a 1.000 tokens base-equivalentes; el consumo depende del modelo XENS usado (ver §3.1) y su multiplicador.
  • Puedes cancelar en cualquier momento; el acceso se mantiene hasta el final del ciclo ya pagado. No se realizan reembolsos por períodos parciales, salvo que la ley indique lo contrario.

3.1 Modelos XENS — correspondencia con proveedores

XENS expone nombres propios para que puedas cambiar de proveedor sin afectar tu flujo. La correspondencia actual es:

  • XENS Flash — Mistral Nemo (Mistral AI vía OpenRouter) — rápido, uso diario
  • XENS Core — DeepSeek Chat (DeepSeek vía OpenRouter) — equilibrado
  • XENS Think — DeepSeek R1 (DeepSeek vía OpenRouter) — razonamiento
  • XENS Code — Qwen 2.5 Coder 32B (Alibaba vía OpenRouter) — código
  • XENS Vision — Gemini 2.0 Flash (Google vía OpenRouter) — imagen/pantalla
  • XENS Ultra — Claude Sonnet 4 (Anthropic vía OpenRouter) / Gemini 2.0 Flash (Google) — frontera

La disponibilidad por plan es: Free (Flash, Core), Lite (Flash, Core, Vision), Pro (Flash, Core, Think, Code, Vision), Premium (todos incluido Ultra). El proveedor subyacente puede cambiar por rendimiento o disponibilidad manteniendo el alias XENS.
