Política de Privacidad

Última actualización: 2026-10-28

Esta Política de Privacidad explica cómo SvY Teck recopila, usa y protege tu información al usar AINSLUP.

1. Información que recopilamos

  • Datos de cuenta: nombre, correo electrónico y, si inicias sesión con Google o GitHub, la información básica de perfil que esos proveedores comparten con nosotros.
  • Conversaciones: la aplicación de escritorio guarda el historial localmente en ~/.ainslup/sessions para poder mostrarlo. Actualmente no sincronizamos automáticamente el contenido completo de las conversaciones con Supabase. Aun así, el texto necesario para responder sí se envía al proveedor LLM elegido.
  • Datos de uso: número de mensajes enviados, plan activo, y eventos de interacción con la interfaz, usados para analítica del producto.
  • Datos técnicos: dirección IP, tipo de navegador/dispositivo y registros de errores, recopilados por la infraestructura y el diagnóstico.

2. Cómo usamos tu información

  • Para operar tu cuenta y mostrar el historial local de tu aplicación.
  • Para procesar tus mensajes y generar respuestas del asistente.
  • Para aplicar los límites del plan gratuito y gestionar suscripciones de pago.
  • Para mejorar el producto mediante analítica agregada de uso.
  • Para comunicarnos contigo sobre cambios en el servicio, facturación o soporte.

3. Qué datos recibe cada proveedor

No vendemos tu información personal. Para generar una respuesta, AINSLUP puede enviar el mensaje, parte del historial necesario, instrucciones del asistente y resultados de herramientas al proveedor seleccionado. No todos los proveedores reciben todos los datos:

  • OpenRouter: recibe la solicitud LLM y puede enrutarla al modelo configurado, por ejemplo DeepSeek, MiMo, MiniMax, Google o Anthropic. OpenRouter y el proveedor final procesan el contenido según sus propias políticas y retención.
  • DeepSeek, Xiaomi/MiMo y MiniMax: reciben el texto que AINSLUP les envía cuando su modelo es seleccionado. No reciben tus claves locales.
  • Google o Anthropic: reciben solicitudes únicamente cuando se selecciona un modelo suyo o actúan como fallback. El texto puede incluir contexto de la conversación y resultados de herramientas necesarios para la tarea.
  • Mistral: puede recibir solicitudes solo cuando se usa una ruta Mistral configurada o un respaldo de emergencia; no es el destino normal de todos los mensajes.
  • Supabase: recibe datos de cuenta, autenticación, licencia, créditos y operaciones necesarias del servicio. El contenido completo de la conversación no se sincroniza automáticamente en la versión actual.
  • PayPal y analítica: reciben únicamente los datos necesarios para pagos, seguridad y métricas de uso. No enviamos el texto completo del chat a la analítica de producto.

4. ¿Se usan las conversaciones para entrenar modelos?

AINSLUP no utiliza tus conversaciones para entrenar sus propios modelos. Sin embargo, AINSLUP no controla las políticas de retención o entrenamiento de cada proveedor externo. La configuración puede cambiar por proveedor, modelo, ruta o contrato. No introduzcas secretos, contraseñas, claves privadas o información regulada en una solicitud salvo que aceptes ese riesgo y hayas comprobado la política del proveedor.

5. Correo, escritorio y herramientas

Las herramientas solo actúan cuando están disponibles para tu plan y, para acciones sensibles, después de tu confirmación. Las credenciales de correo configuradas mediante la aplicación se guardan en el Administrador de credenciales de Windows; AINSLUP no debe mostrar la contraseña al modelo. Si pides leer correo, el contenido recuperado puede incorporarse a la solicitud LLM y llegar al proveedor seleccionado. Las capturas de pantalla, archivos, texto del portapapeles y resultados de comandos pueden tener el mismo tratamiento si los compartes explícita o indirectamente con una tarea.

El modo seguro simula acciones sin enviar correos, escribir archivos ni ejecutar comandos. Puedes bloquear herramientas individualmente y consultar el registro local de actividad.

6. Dónde se almacenan y cuánto tiempo

El historial local se almacena en tu equipo, dentro de ~/.ainslup/sessions. La cuenta, autenticación, créditos, licencias y datos operativos se almacenan en Supabase. Los proveedores LLM pueden conservar solicitudes según sus propias políticas; AINSLUP no puede borrar directamente sus registros.

7. Cómo eliminar tus datos completamente

Para borrar el historial local, usa “Limpiar” en la aplicación y elimina los archivos de %USERPROFILE%\.ainslup\sessions si quieres una eliminación manual completa. Para eliminar cuenta, créditos, licencia y datos asociados de Supabase, solicita la eliminación a svyteck@gmail.com indicando el correo de la cuenta. También debes solicitar la eliminación directamente a los proveedores LLM si necesitas retirar una solicitud que ya fue procesada por ellos; AINSLUP no puede garantizar el borrado de sus copias o logs.

8. Tus derechos

Dependiendo de tu ubicación, puedes tener derecho a acceder, corregir, exportar o eliminar tu información personal. Para ejercer estos derechos, contáctanos a svyteck@gmail.com.

9. Claves, tokens y seguridad

Las comunicaciones con los servicios se realizan mediante HTTPS. Las claves de OpenRouter, Pollinations, Mistral y PayPal de producción se mantienen en secretos del backend y no deben exponerse al navegador. Los tokens de sesión se usan para autenticar las solicitudes. La configuración local puede contener credenciales necesarias para el modo personal; protege tu cuenta de Windows y no compartas la carpeta ~/.ainslup. Aplicamos medidas razonables, pero ningún sistema es 100% seguro.

10. Menores de edad

AINSLUP no está dirigido a menores de 13 años. Si crees que un menor nos ha proporcionado información personal, contáctanos para eliminarla.

11. Cambios a esta política

Podemos actualizar esta Política de Privacidad ocasionalmente. Los cambios relevantes serán notificados a través de la plataforma.

12. Contacto

Para preguntas sobre privacidad, escríbenos a svyteck@gmail.com.
